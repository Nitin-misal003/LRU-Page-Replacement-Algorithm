    How LRU and LRU-K work

    1. Check whether the requested page is already in memory.
    2. If it is present, it is a Page Hit; update its recent-use information.
    3. If it is absent, it is a Page Fault.
    4. If a free frame exists, insert the page.
    5. If all frames are full, choose a victim.
      • LRU: the page whose last use is oldest.
      • LRU-K: the page whose K-th most recent use is oldest. A page used fewer than K times is evicted first.
    6. Replace the victim and continue until all references are processed.

    Research concept vs traditional algorithm
